# Published experiment context

The server experiments cover 50 BioMniBench tasks and compare baseline, oracle,
pruned, generalized, GT few-shot, and V10 SEL transfer conditions. The historical
reports in this repository document the transfer design and the feedback-leakage
fix. Reported scores should be treated as benchmark results tied to the external
judge/runtime versions; this public repository does not include private judge
inputs or raw trajectories.
